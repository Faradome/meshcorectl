# Example scripts

- **`contact_markers.sh`** — draws a map with a marker per contact, using
  [coords2img](https://github.com/fdlamotte/coords2img). Two
  `meshcorectl ... -o json` calls piped through `jq`.
- **`getpos.py`** — queries device position via GeoClue2 (Linux). MIT-licensed,
  by the meshcore-cli project.
- **`ask_mepo_coords`** — a `mepo` map-based coordinate picker (Linux phones).
  MIT-licensed, by the meshcore-cli project.
